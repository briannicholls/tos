# Privacy Policy for Shabigglebot

**Last Updated:** August 2026

## 1. Introduction

This Privacy Policy explains how Shabigglebot ("Bot", "we", "us", or "our") collects, uses, and protects information when you use our Discord bot service.

## 2. Information We Process

Shabigglebot is a simple bot and does not permanently store user data.

While the bot is running, it may temporarily process:
- Discord user IDs
- Discord server IDs
- Message content needed to respond to commands

This information is used in memory only for the current request and is not written to a database or long-term storage.

## 3. How We Use Information

We use temporary runtime information to:
- Operate and maintain the bot's functionality
- Respond to user commands and requests
- Prevent abuse and security issues

## 4. Data Storage

- We do not permanently store personal data.
- Data is processed temporarily while the bot handles a command.
- Once processing is complete, data is discarded.

## 5. Data Sharing

We do **not** sell, trade, or share your personal data with third parties. Data may only be transmitted:
- With Discord (as required by the Discord API)
- When required by law or legal process
- To protect the rights and safety of our users

## 6. Data Security

Because we do not permanently store user data, privacy risk is reduced. We still apply reasonable security practices for the bot and hosting environment. However, no method of transmission is 100% secure.

## 7. User Rights

You have the right to:
- Ask how data is handled
- Stop using the bot at any time

Because no personal data is stored permanently, there is no retained account data to access or delete.

## 8. Third-Party Services

This bot uses the Discord API. Please review Discord's Privacy Policy at https://discord.com/privacy for their data handling practices.

## 9. Changes to This Policy

We may update this Privacy Policy periodically. Continued use of the bot after changes constitutes acceptance of the updated policy.

## 10. Contact Us

This bot does not retain personal data, so no privacy data request process is required at this time.
